## ⚡ Overview
A high-performance, cinematic personal portfolio architected for **Rishi Raj Sharma** (AI & Product Development Engineer, BITM Ballari). Built using modern Vanilla HTML5/CSS3/JavaScript, raw WebGL shaders, dynamic canvas frame scrubbers, and spatial sound synthesis.

### 🌟 Key Features
- **Tsukuyomi Awakening Portal**: Custom canvas lockup with 3.0s progressive eye awakening and crow dispersal sequence.
- **Mangekyō Live Gaze Constellation**: Interactive eye tracking that follows cursor movements and inspects core skill domains.
- **Editorial Project Architecture**: In-depth breakdowns of flagship projects (*Newsroom AI*, *Hospital Management Microservices*, *CNN-Based Media Player*).
- **Amaterasu Contact & Seal Dispatch**: Interactive message dispatch system powered by raw WebGL ghost-cursor smoke shaders.
- **Atmospheric Audio Engine**: Volume slider, instant mute/unmute toggle, synchronized Mangekyō audio, and synthesized Web Audio thunder strikes.

---

## 🛠️ Tech Stack
- **Core**: HTML5, CSS3, JavaScript (ES Modules)
- **Visual & Shaders**: HTML5 Canvas, WebGL, CSS Glassmorphism
- **Audio**: Web Audio API (sub-bass & noise synthesis) + HTML5 Audio
- **Bundler & Tooling**: Vite, TypeScript definitions

## 🚀 Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build
```
